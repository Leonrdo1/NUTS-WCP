# NUTS WCP (NUTS ПУС)

**NUTS WCP** — панель управления сайтом (WordPress Control Panel). Надстройка над штатным WordPress: собственный интерфейс, вход через `/cabinet/`, понятные настройки, локальные аватары, формы обратной связи, перенаправления, SEO-основы и однофайловый установщик стартовой сборки для пустого хостинга.

Русские экраны показывают бренд как **NUTS ПУС** — это одно и то же.

## Состав

- `nuts-admin/` — исходники плагина (устанавливаемый ZIP собирается из этой папки).
- В разделе [Releases](https://github.com/Leonrdo1/NUTS-WCP/releases) публикуются готовые архивы `NUTS-PUS-Nx.y.z.zip` — их устанавливают через «Плагины → Добавить → Загрузить».

## Установка

1. Скачайте `NUTS-PUS-Nx.y.z.zip` из последнего релиза.
2. WordPress → «Плагины → Добавить плагин → Загрузить» → активировать.
3. Панель: `/wp-admin/admin.php?page=nuts-cms`. Вход пользователей: `/cabinet/`.

## Обновление панели

Раздел «Управление → Обновление панели» следит за релизами этого репозитория и обновляет плагин штатным механизмом WordPress (доступно автоматическое обновление).

## Требования

WordPress 6.6+, PHP 8.0+. Ядро WordPress не изменяется: авторизация, роли, REST и системная панель остаются штатными.

## Разработка

Версия в заголовке `nuts-admin.php` и константа `NutsCMS\VERSION` должны совпадать. Формат: системные.разделы.правки. Подробные правила — в README комплекта.
